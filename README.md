# Multi-Agent Research System

A Streamlit-based multi-agent research application that searches the web, scrapes relevant sources, generates a research report, and provides critical feedback.

## Live Demo

[Open the deployed application](https://doc-ques-ans-system.streamlit.app/)

## Technologies Used

- Python
- Streamlit
- LangChain
- LangGraph
- Gemini
- Tavily
- BeautifulSoup
